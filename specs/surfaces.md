# 端与任务

改任何界面前先问：企业主晚上 10 点用一只手，能不能 30 秒做完？

## 企业主手机（Expo）

只做高频、要马上处理的事：

- 今日：待发 / 已发 / 失败，以及「下一档几点、哪个平台」（不做排期网格）
- 审批一篇：通过 / 改一句 / 驳回；若被合规拦截，先读一句原因再决定
- 线索：待跟进列表，改状态，复制微信
- 本地生活：只改当日一句（店休 / 延长营业 / 节令），不填完整档案
- 达人：进行中的合作，备注一句
- 推送：发布失败、待审批、新线索、合规拦截

不做：复杂排期网格、OAuth 填 App Secret、大模型创作台、企业档案全文、广告或权重仪表盘。

## 运营工作台（Next.js，手机 + 电脑）

现有页面都要能在窄屏用。电脑上可以并排预览六平台；手机上改成「一次看一个平台」。

保留：总览、写一篇、创作台、获客、日历、队列、账号、设置、达人。

工作台多做这些，且手机也能完成「改一句 / 看警告」，完整表单可在电脑：

- 设置里维护企业档案与本地生活（城市、商圈、业态、营业时间、地标、方言分寸、节令、受众时区）
- 写稿预览按平台显示合规警告；小红书导流、IG 外链等过不了不能入队
- 挂活动时按平台生成允许的 CTA，不给小红书生成微信号或短链
- 日历按平台窗口 + 档案营业节奏建议时间；海外平台用受众时区
- 获客：活动、短链、线索箱。不做投放、买量、自动回评

## 管理后台（Next.js `/admin` + Docker）

- 企业列表、开通/暂停
- 员工与角色
- 全局模拟发布开关、操作日志
- 本机 Postgres，数据不要再只写 JSON 文件

不做：代运营写稿、改 CTA、管线索、编企业档案正文。那些属于租户工作台和企业主 App。
